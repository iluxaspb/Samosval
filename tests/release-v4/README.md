# Проверка рабочего релиза

Из корня репозитория:

```sh
python3 tools/build-release.py
node tests/release-v4/build.cjs
node tests/release-v4/service-worker.cjs
node tests/release-v4/run-regressions.cjs
```

Проверки не требуют npm-зависимостей. `production-loader.cjs` направляет существующие сценарии `tests/modular/` на `app/src` и собранный рабочий HTML. Он применяется только в тестовом процессе и не входит в приложение.

Сценарии в Node проверяют структуру, совместимость, алгоритмы и модель Service Worker; они не подтверждают поведение реального браузера, вход Firebase и опубликованные облачные правила. После публикации на телефоне проверить установленную рабочую программу, отсутствие табеля, зелёный номер 4.0, сохранение существующих настроек и очереди, работу без сети и возврат в сеть. Тестовая программа остаётся отдельной и имеет красный номер.
