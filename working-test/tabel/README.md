## Подключение

`plugin.js` регистрирует поставляемый плагин `builtin-tabel`; редактируемый код загрузчика виден в обычном менеджере расширений. При открытии вкладки загружается `entry.mjs`; редактор таблицы загружается отдельно. По умолчанию доступ разрешён администратору. Действуют также главное право табеля и объектная ACL. Настройки расширения сохраняются существующим менеджером; выключение/удаление скрывает вкладку и освобождает подписки. Удалённый поставляемый плагин можно восстановить кнопкой менеджера. Данные и очередь при этом сохраняются.

Подключение ограничено тестовым проектом `samosval-offline`. Поставляемый плагин не устанавливается в production/demo. Кодовая интеграция использует только блок менеджера плагинов в `source/core/04-subscriptions.js`: lifecycle, объединение поставляемого кода с настройками и узкий API данных. Остальной файл сверяется побайтно с baseline.

## Возможности

- Заявка на выбранную дату, состав из справочников, заказ обеда на завтра, редактируемый предпросмотр и Web Share/копирование.
- Календарная смена, своя/наёмная техника, люди, индивидуальные часы экипажа, пятидневная форма, материалы и работы. Исключение из смены не удаляет справочник.
- Первый связанный лист по эталону: цвета, секции, две строки своей техники, одна наёмной, сумма экипажа, недели пн–вс и неполная неделя от старта объекта.
- Свободные листы: формулы без исполнения JavaScript, диапазоны, сумма, clipboard, оформление, очистка, undo/redo, автозаполнение, черновики.
- Настройки объекта: работы/материалы, план/факт/остаток, права ролей/UID и допуски машинистов. Перенос объёмов из «Линии» выключен.
- История и явный разбор конфликтов с обеими версиями, автором и временем.

## Хранение и изоляция

Повторно используются прежние `timesheetPeople`, `timesheetEquipment`, `timesheetEntries`, `timesheetMaterials`, `timesheetChanges`, ключи записей, минуты, revision и idempotency-квитанции. `storage-core.mjs` — прежний чистый алгоритм хранения в приватном ES-модуле; старый UI не загружается.

IndexedDB остаётся `dt_timesheet_v1_<project>_<workspace>_<uid>`, версия 1, с прежними stores и форматом очереди. Старые ожидающие операции не мигрируются и не удаляются. Пакеты — до четырёх изменений; большая форма может подтвердиться частично по пакетам. Аккаунты разделены. Плагин не предоставляет запись в коллекции «Линии».

Новые коллекции: `timesheetObjects` (настройки/ACL), `timesheetDays` (начало смены), `timesheetValues` (ручной факт), `timesheetSheets` (листы/оформление). **Серверные правила опубликованы 27.10.2026** в `samosval-offline/(default)` и сверены после перезагрузки Console. Фактическая серверная база, backup, diff и проверки — [FIREBASE-READINESS-20261027.md](proposals/FIREBASE-READINESS-20261027.md). Реальный обмен двух устройств приложения отдельно не проверен; серверные допуски по роли/объекту сохраняются.

Отчёт только читает существующий дневной аудит (до 3000 событий): учитывает прибытие без погрузки, дедуплицирует номера, исключает ГАИ. Неполный/неоднозначный источник явно помечается. Дату/смену плагин хранит отдельно от переключателей «Линии».

## Сборка и проверки

```sh
npm install --prefix tests/timesheet --ignore-scripts --no-audit --no-fund
python3 tools/build-test.py
node tests/tabel/run.cjs
# С Java/Firestore Emulator и Playwright Chromium:
FIRESTORE_EMULATOR_JAR=/absolute/firestore-emulator.jar TABEL_BROWSER_EXECUTABLE=/absolute/chromium node tests/tabel/run.cjs --emulator --browser
```

Локальный QA: `python3 -m http.server 8765 --bind 127.0.0.1`, затем `/tests/tabel/harness.html`. Используются синтетические данные, реальная IndexedDB и настоящий блок менеджера; Firebase не подключается. Playwright берётся из `CODEX_PRIMARY_RUNTIME_NODE_MODULES` либо `TABEL_PLAYWRIGHT_MODULE`.

Тестовый builder включает весь runtime плагина в hash и атомарный cache manifest; прежние build-каталоги сохранены для открытых клиентов. Новая PWA проверена локально, включая реальную смену service worker и холодную загрузку без сети. Это не проверка установленного приложения на физическом Android.
