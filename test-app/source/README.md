# Тестовая версия: исходные модули

Актуальная основа — опубликованная тестовая 3.4.11 из коммита
`ff4e9a8c97526e557e6bb38607e606e88b4df2ee`. Разделение выпущено как 3.4.12.

Редактировать:

- `shell.html` — разметка, обработчики HTML и расположение блоков.
- `core/00…19-*.js` — подключение, состояние, права, авторизация, смены,
  рейсы, очередь, отчёты, архив, справочники и навигация. Порядок указан
  в `../modules.json`. Собираются в один обычный `core.js`, чтобы сохранить
  прежнюю область видимости и доступ из HTML-обработчиков.
- `features/` — монеты, магазин, темы, вибрация, аналитика, история,
  игры и другие самостоятельные блоки. Один файл соответствует одному
  исходному скрипту; загрузка остаётся синхронной на прежнем месте HTML.
- `patches/00…12.js` — читаемые исходники встроенных расширений.
  Сборщик сохраняет их прежние `eval` и `try/catch` границы.
- `styles/` — все исходные CSS-блоки. Сборщик вставляет их в HTML на прежние
  места: порядок каскада, базовые URL шрифтов и момент применения не меняются.
- `service-worker.js` — шаблон существующего тестового worker.

Табель продолжает использовать прежние `../src/features/timesheet-*.js`
и `../src/styles/timesheet-css.css`; PWA — `../src/pwa.js`. Остальные файлы
в старом `../src` относятся к предыдущей архитектуре и не используются
активной сборкой. Их нельзя переносить поверх актуального кода.

После правок из корня репозитория:

```sh
python3 tools/build-test.py
python3 tools/verify-test-modules.py
node tests/coins/standalone.cjs
node tests/pwa/service-worker.cjs
```

`verify-test-modules.py` — контроль текущего механического переноса: сравнивает
логику, CSS, разметку и порядок с исходной 3.4.11. Для будущего функционального
изменения потребуется отдельно обновить ожидаемые отличия и сценарии проверки.

`index-test.html`, `sw-test.js`, `../build-manifest.json` и `../build/<hash>/`
генерируются. Их не редактировать вручную. Публиковать исходники и все результаты
сборки одним коммитом; сохранять предыдущие каталоги build для открытых клиентов.
Сборщик не меняет `index.html`, рабочую базу, правила Firebase и данные браузера.

Для экспорта HTML добавлено встраивание внешних файлов через существующий
`TestPWA.inlineHtml`. Это сохраняет прежний однофайловый результат скачивания.
Интерфейс и бизнес-алгоритмы не перерабатывались. ES Modules и изоляция глобальных
переменных — отдельная будущая задача, не часть этого переноса.
