Автоматические результаты текущего прогона: `tests/tabel-next/results.json`.

| Проверка | Подтверждение |
|---|---|
| Две/три строки своей техники, одна наёмной | Domain-тест; 52 часа персонала без распределения |
| Календарь/неполная неделя/будущий план | Domain; запрет факта будущего дня и дат до объекта |
| Заявка → смена → таблица → смена | Chromium 412×915; 52 → 26 часов, отмена и повтор |
| Весь экран | Chromium 412×915 и 915×412, точные границы viewport |
| Формулы, размеры, фокус клавиатуры | Chromium; арифметика, ширина 140, высота 48, вставка символа без blur |
| Перезапуск/офлайн | Настоящая IndexedDB в Chromium, фиктивный сервер; правка сохраняется после reload |
| Новый объект и шаблон состава | Chromium; объект из заявки, новая таблица без старых часов |
| Конфликты/идемпотентность/отзыв прав | Store-тест и настоящий Firebase SDK + Firestore Emulator |
| Права сервера | Изолированный и интегрированный проекты правил; viewer/disabled/чужой объект/самовыдача ACL запрещены |
| Защита границ | 1098 прежних файлов совпадают с baseline; host изменён только в createObject |
| PWA | Cache manifest, контрольные суммы, офлайн-кэш, отказ повреждённого обновления, отсутствие удаления пользовательских данных |
| Дефолтный локальный режим | Chromium подтверждает 0 обращений к серверному адаптеру |

Не выданы за пройденные:
- физический Samsung S25, S Pen, геометрия настоящей Android-клавиатуры и системный диалог Share;
- синхронизация реальных устройств с действующим сервером: намеренно выключена до применения согласованных правил;
- полный ручной цикл рейсов/TTN действующими операторами, длительное измерение FPS/батареи;
- точное распределение самосвалов «Линии» между дневной и ночной сменами табеля: нет проверенного соответствия ID;
- соответствие проекта rules текущему live ruleset: diff основан на версии из репозитория.

Исторический `tools/verify-test-modules.py` останавливается на проверке количества блоков своего старого baseline ещё до сравнения текущего кода. Для данного PR не ослаблен: добавлен отдельный guard на фактический baseline `5bc6325`, который также проверяет воспроизводимость сборки.

Большие свободные листы показываются частями по 80 строк, а не бесконечным скроллом. Многострочные массовые правки сохраняются по сменам; при конфликте последующие дни не выдаются за сохранённые. Отмена в связанном листе прекращается, если данные уже изменились после отменяемой правки.
