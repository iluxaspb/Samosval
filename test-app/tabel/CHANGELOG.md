# Изменения

## 1.1.0-test.1 — 27.10.2026

- Подключение нового табеля через существующие «Расширения», редактируемый загрузчик, доступы, выключение/удаление/восстановление и освобождение ресурсов.

- Самостоятельные формы смены, экипажа, материалов, справочников, истории и конфликтов.
- Разрешённая тестовая PWA-интеграция, оболочка 3.4.14, весь runtime в атомарном cache manifest.
- Проверки реального менеджера, старой очереди, переключения расширения и настоящего обновления worker/офлайн.
- Общие Firebase rules остаются неприменённым предложением; live-запись не подтверждена.
