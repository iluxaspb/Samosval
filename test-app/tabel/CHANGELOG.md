# Изменения

## 1.1.0-test.3 / приложение 3.4.16 — 28.10.2026

- Единый тестовый выпуск с полным экраном всех разделов и ранее опубликованными правилами Firebase.
- Убрано устаревшее предупреждение об отсутствии опубликованных правил; при первом открытии предлагается сохранить настройки объекта.
- Добавлена интеграционная проверка настоящего сервиса через Firebase SDK и Firestore Emulator: второй клиент, подписка, офлайн-перезапуск и идемпотентное подтверждение.
- Проверяются все шесть разделов на полном экране в портретной и альбомной ориентациях и возврат на «Линию» с прежним состоянием.
