## Что остаётся блокировкой выпуска

1. **Действующий** `node tests/pwa/service-worker.cjs` завершается `Release mismatch ... timesheet-core.js`, потому что изменённые исходники и новые модули не входят в прежний утверждённый cache manifest. Он намеренно не пересобирался без разрешения. Тест кандидатного кэша прошёл отдельно и не подменяет этот результат.
2. Новые серверные правила не опубликованы. Текущие live rules не считывались через Console; успешный локальный эмулятор не доказывает доступ в реальной базе. До согласованной интеграции новые настройки/листы могут оставаться в очереди с явным отказом сервера.
3. Физический Samsung S25, системная клавиатура, стилус, нативный share-sheet и установленная PWA не проверены. Это не отмечено как «прошло».
4. Для старых событий без достоверной отметки прибытия/принадлежности ГАИ отчёт показывает предупреждение. Не сохранившиеся первичные сведения автоматически не восстанавливаются.

Список конкретных защищённых файлов, неприменённые diff, зависимости и риски — в [PROTECTED_CHANGES.md](PROTECTED_CHANGES.md). Ссылка на веб-запуск не выдаётся: тестовый сайт из этой ветки не публиковался.

## Производительность и границы

Новый runtime — около **91 КБ** исходного JS/CSS (около 27 КБ при условном совместном gzip; это оценка сжатия, не измеренный размер сетевых ответов). Тяжёлого стороннего редактора нет. Сетка рисует ограниченное окно; передвижение по страницам сохраняет значения. В Chromium подтверждено отсутствие запроса `editor.mjs` при начальном открытии.

Измерения FPS, расхода батареи, реальной задержки сети и длительной работы на Samsung не проводились. Undo/redo свободного листа действует в текущей сессии; подтверждённая история операций сохраняется отдельно. При откате программы новые данные/очереди удалять нельзя.
