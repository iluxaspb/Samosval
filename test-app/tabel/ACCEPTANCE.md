Имеющийся отдельный `tests/pwa/update-browser.py` требует OS sandbox Chromium и не запустился в текущей root-среде. Это ограничение не обходилось изменением его требований.

## Неподтверждённое

- Реальный обмен двух устройств приложения после публикации правил не проведён. Активный ruleset Firebase проверен перезагрузкой Console; таблица правил и эмуляторные проверки подтверждены отдельно.
- Полный рабочий прогон рейсов/TTN реальными операторами: код сохранён, но такой прогон не проводился.
- Физический Samsung S25/S Pen, системная Android-клавиатура, нативный share-sheet и установленная PWA на устройстве. Chromium mobile emulation этого не заменяет.
- Сведения о старых машинах без достоверного события прибытия/ГАИ: источник помечается неполным, факты не восстанавливаются предположениями.

Первый лист использует открытый JPG-эталон. Web Share имеет редактируемый предпросмотр и fallback; подтверждение доставки не имитируется. Данные «Линии» читаются только для отчёта; автоперенос объёмов выключен. Runtime без тяжёлого UI framework, редактор загружается при открытии таблицы. FPS/батарея/длительная работа на телефоне не измерялись.

Откат описан в [README.md](README.md); резервная ветка сохранена, данные/очередь при откате не удалять.

## Полноэкранный выпуск 3.4.15 / 1.1.0-test.2

27.10.2026: изменены только CSS размещения модуля и метаданные версии/сборки. В Chromium с настоящими стилями оболочки проверены все шесть разделов при размерах 412×915, 915×412, 1280×800 и 412×700: границы модуля совпадают с viewport, шапка и нижнее меню оболочки не перекрывают его. Существующая кнопка «На линию» закрывает модуль, возвращает навигацию и прокрутку страницы.

Пройдены domain, JSDOM UI, plugin service, прежний расчёт монет, service-worker cache и полный браузерный сценарий табеля (ввод, формулы, clipboard, офлайн-восстановление, включение/выключение расширения). Проверка сборки подтвердила синтаксис, все контрольные суммы и воспроизводимость. Дополнительно прошла смена service worker 3.4.14 → 3.4.15: холодная офлайн-загрузка всех 48 ресурсов, сохранность прежних localStorage и IndexedDB. Относительно актуального HEAD отдельно подтверждена неизменность 916 файлов.

Физический Android и реальные серверные правила этим изменением не проверялись. Исторический guard.py от исходной интеграции не проходит на существующем build/a56f826f30325346 из предыдущего выпуска; для этой правки границы проверены отдельно относительно актуального HEAD 144e0db.
