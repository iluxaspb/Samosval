## Реализовано

- «Заявка», выбор даты, состав из существующих справочников, отдельный заказ обеда строго на завтра, отчёт по выбранному дню. Перед передачей в Web Share API — редактируемый предпросмотр; запасное копирование. Подтверждение доставки не выдумывается.
- «Смена»: навигация по календарным дням; техника, люди, материалы/работы; состав заявки добавляется только при начале нового дня, без часов. Ручные изменения относятся к выбранному дню. Ранее исключённый состав автоматически не восстанавливается.
- Ввод часов одного агрегата за 5 дней, расширение диапазона до 31 дня; индивидуальные часы экипажа, локальный черновик и исходные ревизии. Наёмная техника — без экипажа.
- Первый обязательный лист с жёлтыми датами, оранжевым адресом, чёрными секциями и цветами эталона. Своя техника имеет две строки, наёмная одну. Строка экипажа показывает сумму; её нажатие открывает детали. Старые поступления материалов видны отдельно и открывают существующую форму.
- Первый лист читает и меняет **существующие `timesheetEntries`**, а не копию часов. Недели строго пн–вс, начиная с фактического старта объекта. День/ночь наследуются из существующего переключателя табеля. Период фильтрует отображение, не данные.
- Независимые свободные листы и листы по шаблону; формулы, диапазон, сумма, копирование/вырезание/вставка, оформление, очистка с сохранением стиля, очистка всего, отмена/повтор, изменение размеров. Маркер заполнения и действие в меню. Поддержаны `=A1`, арифметика, `SUM`/`СУММ`; без исполнения JavaScript.
- Компактная полоса символов сохраняет курсор и фокус; положение рассчитывается через VisualViewport. Фактическая Android-клавиатура ещё не проверена на телефоне.
- Индивидуальные планы работ, материалы/направления, план/факт/остаток, цвет ячеек, права по роли/UID, допуски машинистов по объекту. Перенос объёма «Линии» выключен и не включается без согласованного алгоритма.
- Сохранение через прежнюю IndexedDB-очередь и ревизионные транзакции. Конфликт показывает автора, время, место и полные снимки до/после. Выбор пользователя сохраняет снимок разбора локально.

## Изоляция и данные

Меняются только `test-app/src/features/timesheet-core.js`, `test-app/src/features/timesheet-app.js`, `test-app/tabel/**`, `tests/tabel/**`. Другие 854 исходных файла сверяются с baseline по git blob hash.

`timesheet-app.js` содержит узкий адаптер: контекст, чтение, сохранение табельных операций, черновики и подписки. Никаких записей в коллекции «Линии» API не предоставляет. Новый UI загружается через `import()` при открытии, редактор — при переходе в таблицу. Изменения главной навигации и HTML не требуются.

Повторно используются `timesheetPeople`, `timesheetEquipment`, `timesheetEntries`, `timesheetMaterials`, `timesheetChanges` и прежние ключи/минуты/ревизии. Дополнительные коллекции в существующей тестовой рабочей области:

| Коллекция | Содержание |
|---|---|
| `timesheetObjects` | Настройки, план заявки, работы, материалы и ACL объекта; схема 1 |
| `timesheetDays` | Явное начало календарной смены; без искусственных будущих дней |
| `timesheetValues` | Ручной факт работы/материала по объекту, дате и смене |
| `timesheetSheets` | Независимые листы; отдельный документ оформления связанного листа |

Операции сохраняют автора, время, revision, lastOpId и снимки до/после. Пакеты содержат до четырёх строк, как в прежнем табеле. Вся многодневная форма **не объявляется одной серверной транзакцией**: при конфликте отдельного пакета остальные могут быть подтверждены; очередь показывает каждый результат. Черновики сохраняются на устройстве, после постановки в очередь несинхронизированная версия остаётся в этой очереди.

Для записей используются запросы выбранных месяцев и объекта. Подписки прекращаются при закрытии модуля; повторное чтение активного диапазона использует уже открытую подписку. Сетка рисует до 60×21 связанных или 40×16 свободных ячеек; остальной диапазон доступен страницами. Свободный лист: до 1000×100, до 5000 непустых/оформленных ячеек и 240000 символов в документе. Собственные библиотеки UI/формул; тяжёлый framework не добавляется.

## Отчёт и «Линия»

Читается сохранённый аудит выбранного московского календарного дня: запрос по одному индексируемому полю `timestamp`, максимум 3000 событий; затем фильтрация объекта. Это позволяет учитывать прибывшую и позже уехавшую без погрузки машину, даже если событие вышло из последних 200 записей главного экрана. Машины объединяются по ID/нормализованному госномеру, ГАИ исключаются. Фактический состав прочей техники берётся из смены.

Старые события без признака прибытия или данных для исключения ГАИ восстановить достоверно нельзя. При неоднозначности, недоступной сети или превышении лимита отчёт явно предупреждает о неполном источнике. Ни загрузка, ни мгновенный счётчик «На линии» не используются как условие включения самосвала. Первичные данные «Линии» остаются нетронутыми.

## Запуск и проверки

Из корня репозитория:

```sh
npm install --prefix tests/timesheet --ignore-scripts --no-audit --no-fund
node tests/tabel/run.cjs
python3 -m http.server 8765 --bind 127.0.0.1
```

Безопасная локальная QA-страница: `http://127.0.0.1:8765/tests/tabel/harness.html`. В ней синтетические пользователи и имитация сервера; используются настоящие IndexedDB и браузерные модули. Она не подключена к Firebase и не включена в приложение.

`index-test.html` использует существующую тестовую авторизацию и Firebase. Не открывать этот PR как готовое обновление установленной PWA: защищённые манифест и worker ещё содержат прежние контрольные суммы.

```sh
# Java + Firestore Emulator jar; реальная Firebase не используется:
FIRESTORE_EMULATOR_JAR=/absolute/path/firestore-emulator.jar node tests/tabel/run.cjs --emulator

# Дополнительно Playwright Chromium:
TABEL_BROWSER_EXECUTABLE=/absolute/path/chromium/headless_shell node tests/tabel/run.cjs --browser

# Создать предложения, не меняя ни один защищённый файл:
python3 test-app/tabel/prepare-protected-diffs.py
python3 tests/tabel/guard.py
```

Для `browser.cjs` используется Playwright из `CODEX_PRIMARY_RUNTIME_NODE_MODULES`; в иной среде путь к установленному Playwright можно передать через `TABEL_PLAYWRIGHT_MODULE`. Автоматическая проверка не заменяет физический Samsung S25.
