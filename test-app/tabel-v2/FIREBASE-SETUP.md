# Включение Firebase для Табеля 2 — 3.4.33

Только проект `samosval-offline`, база Firestore `(default)`, пространство `main_workspace`.

1. Сохраните копию текущих опубликованных Firestore Rules.
2. Файл `firestore-tabel-next-test.rules` — полный вариант на основе репозиторного `firestore-timesheet-test.rules`. Перед заменой сравните текущие правила с этой основой. Если в консоли есть дополнительные изменения, сохраните их: добавьте блок «Табель 2» и исключите `tabelNextRecords`, `tabelNextOperations`, `tabelNextMeta` из ОБОИХ общих wildcard-условий read/write. Не заменяйте отличающиеся текущие правила вслепую.
3. Опубликуйте объединённые правила через Firestore Database → Rules → Publish.
4. Firestore Database → Data: создайте документ `workspaces/main_workspace/tabelNextMeta/config` с двумя полями: `enabled` типа boolean со значением true и `schema` типа number со значением 1.
5. Откройте тестовый сайт 3.4.33 и заново откройте «Табель 2». Если до этого работали на нескольких устройствах, дождитесь отправки с первого перед открытием второго. Существующие различающиеся версии будут доступны в «Конфликтах», без автоматического перетирания.
6. Проверьте изменение часов на первом устройстве, появление на втором и сохранность после перезагрузки. Внизу не должно быть ошибки Firebase; очередь должна стать пустой. Посмотрите документы в `tabelNextRecords` и журнал `tabelNextOperations` в консоли. До этой проверки реальная межустройственная работа не подтверждена.

Отключение: enabled=false, затем закрыть и заново открыть модуль. Локальную базу и очередь не очищать. На уже открытые экземпляры переключатель действует после повторного открытия.

Проверки выпуска: 32 domain-теста; full-browser и release-3432-browser; настоящий SDK Firebase + эмулятор, два изолированных контекста Chromium, роли editor/reader/disabled, конфликты, повтор после потерянного подтверждения и история. Реальная база недоступна агенту; правила публикует пользователь.

Этот выпуск содержит онлайн-часть. Ранее согласованные новые изменения интерфейса (табличные люди, раскладка категорий, темы и др.) ещё не входят в него.
