## Возможности
- Вход без активной смены или объекта Линии. Создание общего объекта в заявке (существующее право manage_objects).
- Выбор общей техники/людей, добавление позиций в локальную базу, сохранение состава по умолчанию.
- Шесть отдельных окон настроек, поиск с сохранением отметок.
- Своя техника: часы машины и обезличенные часы персонала; опциональная помпа. Наёмная: только часы техники.
- Прямой ввод из таблицы и смены, прошлые/будущие даты, день/ночь, компактные заголовки.
- Форматирование, размеры строк/столбцов, свободные листы, безопасные арифметические формулы, копирование, история.
- План/факт/остаток только для видов работ; общий локальный справочник материалов и работ.
- Прибытия из доступной истории Линии учитываются с дедупликацией ID/номера и исключением ГАИ. Неполная история явно отмечается.

## Сохранение и границы
Данные сохраняются в IndexedDB отдельно для проекта, пространства и пользователя. Старые localStorage-черновики автоматически копируются при первом открытии объекта; исходник сохраняется для отката. Между устройствами данные НЕ синхронизируются. Очистка данных браузера удалит локальный табель.
Общие справочники читаются с сервера; новые позиции пока сохраняются только на устройстве. Новый объект записывается в существующий общий справочник объектов с проверкой действующих прав.
Вход и запись используют существующие права timesheet / timesheet_edit. Гранулярные права из permissions.mjs пока не встроены в Админ. Серверный адаптер выключен: общие Firebase Rules не изменялись. Перенос материалов подключён к закрытию Линии: после сохранения архива, до очистки рейсов. Материал и направление берутся из настроек объекта, недостающие значения запрашиваются и сохраняются локально. ID смены защищает от повторного импорта. Отмена или ошибка переноса оставляет архив и исходные рейсы для повторной попытки закрытия. Перенос работает на устройстве закрывающего смену пользователя.
