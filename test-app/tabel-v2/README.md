# Подготовлено 3.4.51: Excel, PDF и совместное выделение

Импорт .xlsx добавляет до 20 независимых листов, не заменяя связанный табель. Книги с формулами между листами экспортируются группой. Импорт доступен администратору и прорабу; экспорт и PDF — при праве просмотра листа.
Сохраняются значения, формулы, базовое оформление, исходные стили Excel, темы, именованные диапазоны, объединения и размеры. Редактор вычисляет арифметику и SUM/СУММ; остальные формулы сохраняются для Excel и не исполняются как код. Для пересчёта сложных функций нужен Excel. Диаграммы, макросы и условное форматирование не импортируются. Старый .xls нужно сначала преобразовать в .xlsx.
Ограничения: 8 МБ на файл, 1000 строк × 100 столбцов и 350 КБ сериализованных данных на лист; PDF до 30 000 ячеек. Большие листы отклоняются без обрезания. Каждая страница PDF рендерится отдельно, чтобы длинные таблицы не превысили лимит canvas.
Присутствие: цвет имени совпадает с рамкой точного диапазона ячеек. Отдельная подписка на объект/лист; запросы и серверные правила учитывают доступ к листу. Ушедшие пользователи удаляются, при внезапном отключении отметки устаревают через 125 секунд. Heartbeat 45 секунд; выделение отправляется с задержкой 200 мс. В очередь данных и аудит присутствие не попадает.

Правила присутствия опубликованы с разрешения пользователя 29.10.2026 в samosval-offline, активная ревизия 06:33 по Москве. Полный текст после повторного открытия совпал с проверенным файлом. Тестовая сборка 3.4.51 подготовлена и выпускается через PR #31. Подробный отчёт: releases/3.4.51/REPORT.md.

## Возможности
- Вход без активной смены или объекта Линии. Создание общего объекта в заявке (существующее право manage_objects).
- Выбор общей техники/людей, добавление позиций в локальную базу, сохранение состава по умолчанию.
- Шесть отдельных окон настроек, поиск с сохранением отметок.
- Своя техника: часы машины и обезличенные часы персонала; опциональная помпа. Наёмная: только часы техники.

## Сохранение и границы
Данные сохраняются в IndexedDB отдельно для проекта, пространства и пользователя. Старые localStorage-черновики автоматически копируются при первом открытии объекта; исходник сохраняется для отката. Между устройствами данные НЕ синхронизируются. Очистка данных браузера удалит локальный табель.
Общие справочники читаются с сервера; новые позиции пока сохраняются только на устройстве. Новый объект записывается в существующий общий справочник объектов с проверкой действующих прав.
Вход и запись используют существующие права timesheet / timesheet_edit. Гранулярные права из permissions.mjs пока не встроены в Админ. Серверный адаптер выключен: общие Firebase Rules не изменялись. Перенос материалов подключён к закрытию Линии: после сохранения архива, до очистки рейсов. Материал и направление берутся из настроек объекта, недостающие значения запрашиваются и сохраняются локально. ID смены защищает от повторного импорта. Отмена или ошибка переноса оставляет архив и исходные рейсы для повторной попытки закрытия. Перенос работает на устройстве закрывающего смену пользователя.
