# Табель 2 — тестовая версия 3.4.29

Полный встроенный экран: Заявки, Смена, Таблица, Справочник, Настройки, История.
Точка входа: `entry.mjs`; таблица загружается по требованию. Старый `test-app/tabel` не изменён.
Актуальные требования: PLAN-2026-10-28.txt. Эта версия — тест интерфейса и локальной работы, а не завершение всех требований плана.

## Возможности
- Вход без активной смены или объекта Линии. Создание общего объекта в заявке (существующее право manage_objects).
- Выбор общей техники/людей, добавление позиций в локальную базу, сохранение состава по умолчанию.
- Шесть отдельных окон настроек, поиск с сохранением отметок.
- Своя техника: часы машины и обезличенные часы персонала; опциональная помпа. Наёмная: только часы техники.
- Прямой ввод из таблицы и смены, прошлые/будущие даты, день/ночь, компактные заголовки.
- Форматирование, размеры строк/столбцов, свободные листы, безопасные арифметические формулы, копирование, история.
- План/факт/остаток только для видов работ; общий локальный справочник материалов и работ.
- Прибытия из доступной истории Линии учитываются с дедупликацией ID/номера и исключением ГАИ. Неполная история явно отмечается.

## Сохранение и границы
Данные сохраняются в IndexedDB отдельно для проекта, пространства и пользователя. Старые localStorage-черновики автоматически копируются при первом открытии объекта; исходник сохраняется для отката. Между устройствами данные НЕ синхронизируются. Очистка данных браузера удалит локальный табель.
Общие справочники читаются с сервера; новые позиции пока сохраняются только на устройстве. Новый объект записывается в существующий общий справочник объектов с проверкой действующих прав.
Вход и запись используют существующие права timesheet / timesheet_edit. Гранулярные права из permissions.mjs пока не встроены в Админ. Серверный адаптер выключен: общие Firebase Rules не изменялись. Автоматический перенос материалов при закрытии смены НЕ подключён: архив Линии не содержит надёжных исторических material/destination ID. Проверенная функция предложения переноса в domain.mjs не означает готовую интеграцию.

## Проверки
`node --test tests/tabel-v2/*.test.mjs`
`node tests/tabel-v2/full-browser.cjs` (Playwright и Chromium через PLAYWRIGHT_PACKAGE / CHROMIUM_PATH).
Браузерный тест использует подставной host без реальных пользовательских данных: viewport 393×852, вход без смены, миграция, шесть окон, поиск, прямой ввод 52→26, компактные даты, справочники, новый объект, состав по умолчанию, формула, повторное открытие и отзыв доступа.
`node tests/modular/line-motion-3425.cjs` и `line-motion-3426.cjs` проверяют неизменность поведения анимаций Линии.
Сборка: `python3 tools/build-test.py`; все хеши manifest проверяются. Физический Android, перо и реальная авторизованная Firebase-сессия не проверены.

## Откат
Откатить релизный коммит тестовой версии, пересобрать тестовые assets. Не очищать localStorage/IndexedDB: старый исходный черновик и новые данные сохраняются. Production index.html, sw.js, app/, старый табель и Firebase Rules не меняются.
