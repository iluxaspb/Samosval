# Изоляция кеша NAS-кандидата

После публикации TEST 4.0.1 обнаружено, что кеш кандидата nas-preview и основной TEST использовал одно имя при одинаковом build ID. Кеши Cache Storage общие для origin; ошибка установки кандидата могла удалить кеш основной страницы. В опубликованном nas-preview/sw-test.js префикс изменён на samosval-nas-preview-shell-. Основной worker и все 95 ресурсов основного релиза c00043cfa3b6e557 не изменены. Новый candidate worker очищает только свой префикс. При следующем обновлении изолированного кандидата обязательно сохранять этот отдельный префикс; нельзя копировать основной sw-test.js без адаптации PREFIX.
