# Обновление тестовой PWA

Версия 3.4.19 добавляет в настройки кнопку «Проверить и установить» и ссылку «Открыть страницу восстановления обновления»: https://iluxaspb.github.io/Samosval/update-test.html.

Кнопка проверяет свежий `test-app/build-manifest.json` напрямую на сайте, вызывает `registration.update()`, дожидается полного проверенного PWA-кеша и после подтверждения пользователя отправляет сообщение `TEST_PWA_APPLY`. Ожидающий Service Worker вызывает `skipWaiting()` только при наличии полного кеша и совпадении версии.

Для старых установок страница `update-test.html` располагается вне области старого Service Worker и проверяет контрольную сумму HTML, согласованность manifest и Worker. Она удаляет только регистрацию тестового Service Worker, не удаляя кеши и пользовательские данные. Новый Worker создаёт кеш, а старые `samosval-test-shell-*` удаляются только после успешной активации. При ожидающих локальных рейсах обновление заблокировано. Рабочие `index.html`, `sw.js`, Firebase и табель не затронуты.
