## Найденные и исправленные блокирующие ошибки

1. **Неучтённая migration_probe_evidence.** Её создал прежний cleanup-nas-probe.sql. Исходная SQL 014 отвергала реальную базу. [PR 69](https://github.com/iluxaspb/Samosval/pull/69) сохраняет эту таблицу, допускает только известную двухколоночную структуру и по-прежнему отвергает неизвестные таблицы. Проверка на восстановленной NAS-копии: 39 триггеров, 1 cursor, 0 replica receipts; исходные данные не изменились.
2. **docker-input-failed при pg_restore --list.** Первая реальная попытка безопасно остановилась до SQL и переключения API. Причина: команда чтения оглавления завершалась раньше передачи всего дампа. [PR 70](https://github.com/iluxaspb/Samosval/pull/70) дочитывает поток и сохраняет реальный код pg_restore. Проверены 8-МБ поток/ненулевой код отказа и настоящий дамп через Node/Docker на NAS: `REAL_NAS_NODE_DUMP_STREAM_VERIFIED 13229`.
3. **Медленная проверка 36 файлов.** По одному контейнеру на файл требовало почти 9 минут. Теперь каждый файл по-прежнему проходит node --check, но в одном изолированном контейнере. Регрессия отклоняет синтаксически неверный модуль.

## Оставшаяся приёмка — НЕ объявлять выполненной

На момент этой записи расширенные приёмочные тесты после установки ещё не завершены. Подготовлены девять серверных наборов для отдельной пустой БД на этом NAS: гонки погрузок, повторные операции, отмена/восстановление, табель, старт/закрытие смен, архив и транзакционный outbox; также замер задержки 100 откатываемых записей.

Первая попытка приёмочного скрипта остановилась из-за docker cp в read-only API-контейнер. Это ошибка скрипта проверки, не ошибка установленного сервера; состояние приложения не менялось. Исправление читает ожидаемый манифест через stdin и передаёт тесты через tar в уже существующий tmpfs worker, не ослабляя read-only.

Нужны результат этих NAS-тестов, независимый подсчёт live-триггеров/записей и SHA-256 установленного кода. Реальное отключение сети на двух отдельных учётных записях в облачном браузере ещё не проверено; прогоны CI/серверных повторов не следует называть такой проверкой.

Обнаружено перекрытие внутренней навигации центра управления нижним меню frontend. Для установки раздел был открыт клавиатурой. Frontend не менялся; дефект требует отдельной правки.
