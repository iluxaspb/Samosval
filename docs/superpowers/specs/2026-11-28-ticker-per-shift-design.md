# Дизайн: зелёная полоса уведомлений по выбранной смене

## Цель
В тестовой версии при нескольких открытых сменах уведомления не должны смешиваться. Единственная зелёная полоса показывает последнее действие только выбранной смены; вкладки других смен показывают точку, если там есть непросмотренное действие.

## Подтверждённые требования
- Действия и уведомления фильтруются по `shiftId` выбранной смены.
- При переключении смены полоса сразу обновляется на последнее уведомление этой смены или скрывается, если уведомлений нет.
- На вкладке смены появляется индикатор непросмотренного уведомления.
- Точка гаснет, когда пользователь выбирает смену и тем самым просматривает её полосу.
- Отметки просмотра хранятся локально отдельно по сменам; серверные уведомления и журнал не меняются.

## Подходы
1. Фильтровать общие уведомления для полосы по выбранной смене, хранить отметку последнего просмотра на устройстве и показывать точку на вкладке при наличии более новых записей. **Выбран:** минимально меняет существующую механику одной полосы и использует уже имеющиеся `shiftId`.
2. Отдельная полоса для каждой смены. Не выбрано: занимает дополнительное место на мобильном экране и не соответствует просьбе о полосе выбранной смены.
3. Серверная разметка прочитанности на пользователя и смену. Не выбрано: меняет хранение и синхронизацию без необходимости — требование покрывается локальным просмотром.

## Ограничения и нецели
- Рабочую версию и рабочую базу не менять; изменение только в тестовом канале.
- Не переписывать уведомления и не менять права отмены (undo).
- Уведомления без `shiftId` не должны попадать в полосу конкретной смены.
- Существующие правила валидации уведомлений сохраняются, включая показ погрузки только после подтверждённого рейса.

## Детали, оставленные исполнителю
- Фильтрация в `lastValidNotification`/рендере полосы по `state.shift.id`.
- Локальная отметка просмотра по каждой смене (timestamp), переживающая перезагрузку страницы.
- Индикатор непросмотренного действия на вкладке смены, гаснущий при выборе.
- Обновление полосы и индикаторов при каждом новом уведомлении и при переключении смены.
- Тесты: разделение A/B, скрытие пустой полосы, сброс точки при выборе, сохранение точки на другой смене, валидация погрузки.
