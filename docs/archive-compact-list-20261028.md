# Архив: компактные адреса и список смен (TEST 3.4.21)

Зафиксировано 28.10.2026. Вкладка «Архив» по умолчанию отображает только адреса/объекты в свёрнутом виде. Нажатие на заголовок адреса раскрывает архивные смены этого объекта; повторное нажатие сворачивает. Адреса независимы. Состояние раскрытия сохраняется при перерисовке списка, а поиск по дате или объекту разворачивает совпавшие результаты.

Каждая строка смены содержит дату, число **обычных** рейсов и общий объём в м³. Надпись «ГАИ: N рейсов» в списке смен не показывается. Данные рейсов ГАИ и отдельный лист ГАИ внутри архива **не удаляются и не изменяются**. Логика хранения, восстановления, экспорта и оформления листов остаётся прежней.

Код: `test-app/source/core/10-archive.js` → `renderArchive()`; опубликованный тестовый бандл `test-app/build/9580be34b9aa55d4/core.js`. Рабочая версия `index.html` и `sw.js` не изменены.
