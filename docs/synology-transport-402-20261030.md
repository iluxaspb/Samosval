Безопасная диагностика сообщает этап и тип нарушения ответа. Неизвестный результат записи сохраняет uncertain и исходный ID операции.

Обновлённый NAS API добавляет ETag/304 только после авторизации и построения полного ответа GET. Клиент использует проверенную копию только в памяти своего сеанса; при выходе память очищается. Отзыв прав возвращает 403 даже при совпадающем ETag. POST не получает 304. CORS разрешает If-None-Match и открывает ETag. Старый сервер без ETag совместим: клиент не отправляет новый заголовок до получения корректного ETag.
