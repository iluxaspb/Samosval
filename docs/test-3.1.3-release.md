# Тестовая публикация 3.1.3 — 25 октября 2026

Включено в index-test.html:

- «Админка → Отчёт о работе»: полный согласованный список, реальные статусы, ограничения, дальнейший план, проверки и шаблоны сообщений об ошибках.
- Автор уже сохранённого приезда, погрузки или ТТН в конфликтном уведомлении. Старые записи без имени явно обозначаются. Дополнительный рейс и отдельный сетевой запрос ради имени не создаются.
- Переключатели доступных функций с подробным описанием. Ещё не реализованные и не включённые пункты обозначены, их переключатели недоступны.

Сохранено отдельно в ветке test-v3-3: табель 3.2, новые роли, сброс таймера старшим прорабом, значки, подготовленные правила Firebase, полный список требований и анализ синхронизации. Эти изменения требуют проверки и применения новых правил в тестовой базе samosval-offline до включения на действующей странице.

Основной index.html, рабочая база, расчёт рейсов, очередь синхронизации и назначения пользователей этой публикацией не изменяются. Новых правил Firebase эта публикация не требует: она не добавляет коллекций и не меняет права ролей. Сохранение настроек отчёта использует существующее администраторское право settings/appConfig.

Проверка владельцем:

1. Открыть index-test.html, обновить страницу, убедиться в версии 3.1.3 · тест.
2. Администратором открыть «Отчёт о работе». Найти план и нужный пункт, раскрыть «Подробно».
3. В «Патчах» выключить отчёт, убедиться, что вкладка скрылась, затем включить обратно.
4. На двух аккаунтах отметить одну погрузку. В журнале остаётся один рейс, второй участник видит автора сохранённого действия. Повторить с приездом и ТТН.
5. Проверить повторную отправку после офлайна. Имя должно относиться к исходному действию, а не к более позднему рейсу.

Автотесты не заменяют проверку этих сценариев на реальных телефонах.
