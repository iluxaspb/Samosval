# Табель: NAS-host основного интерфейса — TEST-кандидат

Существующий UI табеля подключён к фабрике серверного транспорта. В NAS-ветке entry/workspace/material-transfer выбирают только NAS remote, а не создают Firestore remote; отсутствующая фабрика даёт ошибку. Текущие формы, формулы, renderer и mergeRecord сохраняются.

Новая storageScope разделяет IndexedDB/локальный кэш NAS по origin, workspace и UID; прежнее имя Firebase IndexedDB сохраняется. При смене источника или экземпляра сессии окно не переиспользует старый transport. Старые Firebase-черновики автоматически в NAS не импортируются. Справочник читается из NAS _catalog/config. Участники читаются из /api/v1/members. Основной runtime также загружает объекты из каталога NAS; поздний ответ после отзыва доступа не применяется. Для роли только с timesheet без line/trucks серверный доступ к списку объектов требует отдельной проверки/доработки — текущий readCatalog допускает line/trucks.

Удалённый _catalog/config/_defaults/config теперь передаётся в Store как data:null, чтобы не оставлять старую запись в кэше. Отправка правок использует прежнюю устойчивую Store-очередь и ID; сетевой await не блокирует локальное сохранение. Сообщения очереди показывают Synology, когда выбран NAS.

Проверки: 5 сценариев NAS/Firebase-изоляции, выбора фабрики без Firestore, повторной отправки реальной Store-очереди с сохранением ID/формул/цветов/размеров и доставки удаления конфигурации; 2 проверки реального core NAS-host и остановки сессии. Локально 97 tests/tabel-v2/*.test.mjs прошли без ошибок и пропусков. Модульный аудит прошёл: 33 модуля, 67 source-файлов, 94 asset, синтаксис, SHA256, детерминированная сборка, production untouched. Объединённый CI с PostgreSQL проверяется отдельно.

Ограничения: это подключение в коде кандидата. Маркер NAS не добавлен в опубликованный TEST; браузерный цикл и IndexedDB в реальном браузере ещё не проверены. Transient presence/цветные совместные выделения не перенесены: в NAS нет скрытого обращения к Firestore presence и показывается отдельное сообщение. Создание объекта из табеля ожидает подключения справочников. Игровые операции, настройки, смены и архивные мутации ещё требуют завершения. Общий старый legacy-прогон с расходящимися source/src ожиданиями остаётся незелёным; успешный CI этого этапа его не подменяет. Фотографии исключены из миграции по указанию пользователя.

Полный тестовый релиз 4.0 не выпущен.
