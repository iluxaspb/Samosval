# Проверка внешнего Synology API из TEST

Изменение дополняет интерфейс TEST 3.4.63 из PR48: используется существующий индикатор и один блок настроек сервера. В нём добавлена кнопка «Проверить Synology», доступная активному администратору после загрузки прав и при наличии сети.

Проверка делает только авторизованные GET линии и табеля через существующий HTTPS-адрес. Проверяет формат, workspace, ревизию, HTTP-ошибки, однократное обновление токена и таймаут. Ответ старого API линии при отсутствии API табеля не считается готовностью. Смена пользователя или отзыв доступа убирает результат и запрещает показ запоздалого ответа. Повторное нажатие во время проверки не запускает второй запрос. В результатах показываются только счётчики; ГАИ исключён из обычного объёма.

Проверка не переключает сервер, не двигает локальные очереди и не меняет индикатор F на S. Токены не сохраняются и не выводятся. Synology как основной источник всех экранов и репликация Firebase ещё не готовы. Production, Rules, данные NAS и фото не изменяются.

Добавлены восемь транспортных тестов и проверка обработчика интерфейса. Новый модуль включён в входы сборщика и офлайн-кэш. Стандартный CI пересобирает HTML/manifest/service worker из исходников и проверяет целостность, детерминизм, регрессии и мобильный интерфейс. Сгенерированные артефакты не публикуются этим draft PR.

Доступная сессия DSM снова требует входа. Существующий внешний HTTPS-маршрут этим этапом не менялся. После восстановления доступа необходимо проверить и направить тестовый маршрут на установленный API-кандидат, затем продолжить перенос оставшихся обработчиков и экранов.
