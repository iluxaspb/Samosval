# Совместное выделение табеля — TEST NAS

Добавлен GET/POST /api/v1/tabel/presence и NAS-клиент текущего UI выделений. Имена/цвета/диапазоны использует прежний renderer; UID, имя и seen формирует сервер. Клиентские uid/name/seen игнорируются. Доступ к каждому листу проверяется теми же PostgreSQL ACL, что чтение табеля, без загрузки большого содержимого листа. Перед выдачей повторно проверяется доступ читателя; отозванные участники удаляются из выдачи.

Выделения временны: память одного API-процесса, TTL 120 секунд, максимум 256 записей и 8 активных сессий пользователя. Присутствие не пишет в PostgreSQL, историю, аудит, офлайн-очередь или Firebase. При рестарте API отметки очищаются. Для нескольких одновременно обслуживающих API-процессов потребуется общее transient-хранилище; такая конфигурация сейчас не заявляется.

Клиент опрашивает участников раз в 4 секунды, обновляет heartbeat раз в 20 секунд и отправляет изменение диапазона с debounce 200 ms. Номер последовательности защищает от поздних старых обновлений и восстановления удалённой отметки. При смене листа/выходе/отзыве доступа запоздалые ответы не рисуют старые выделения. Обычный выход из приложения предварительно ожидает очистку до 1.5 секунды; скрытие/закрытие окна удаляет отметку best effort. При резком обрыве связи действует TTL, мгновенное удаление при отсутствии сети не обещается.

Проверки локально: сценарии подмены личности/времени, ограничения диапазонов, изоляции объектов/листов, отзыва прав, TTL, запоздалых запросов, лимитов, скрытия/закрытия, перехода на другой лист и ошибок соединения прошли. Все 97 проверок логики табеля также прошли. Модульная сборка, синтаксис и SHA256 проверены. PostgreSQL-сценарий ACL входит в полный CI; результат этого запуска фиксируется отдельно, без подмены локальным skipped.

Серверная установка этого изменения и реальный браузерный круг ещё не подтверждены на момент подготовки PR. Основной TEST остаётся Firebase; NAS-маркер не опубликован. Полный 4.0 не выпущен. Фото исключены из миграции. Оставшиеся задачи: справочники/смены, игровые операции/настройки, архивные мутации, права timesheet-only на объекты, браузерные сценарии и старые legacy-регрессии.
