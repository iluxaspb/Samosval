# Эталон сортировки: «Сводка»

Дата согласования: 28.10.2026.

Обязательное правило для белого табличного листа вкладки «Сводка»:

1. Самый верхний самосвал — тот, который **первым совершил погрузку (первый засчитанный рейс) в текущей смене**.
2. Остальные самосвалы, имеющие рейсы, идут **по возрастанию времени своей первой погрузки** (от ранней к поздней).
3. **Все самосвалы без единого рейса находятся в самом низу** списка, после всех машин с рейсами. Отсутствие рейса нельзя приравнивать к нулевому времени, иначе машина ошибочно поднимется наверх.
4. Внутри строки самосвала рейсы располагаются **слева направо в хронологическом порядке**: «Рейс 1», «Рейс 2», «Рейс 3» и т. д.
5. В графе «Самосвал» объём дополнен числом рейсов в формате **«24 м³ / 2 р»** (не словом «рейс»).
6. Архивный лист каждой закрытой смены повторяет ту же сортировку и формат, включая машины без рейсов внизу.
7. Не менять этот эталон без отдельного указания пользователя.

Сортировка относится к обычным и ГАИ листам «Сводки» и «Архива». Формат «м³ / р» — к обычным листам; ГАИ отображает «Рейсов: N». Актуальные исходники: `test-app/source/core/09-reports.js`, `test-app/source/features/paper-viewer.js`.

Изменения рабочей версии приложения этим правилом не запрашивались.
