## Статус последних требований (источник — `docs/test-3.3-requirements.md` и последующие; проверять по коду, не по планам)

1. Обязательное прибытие перед погрузкой — реализовано и проверено: серверные правила линии допускают погрузку только после прибытия (`server/src/line-rules.mjs`, тесты `server/tests/`).
2. «Время ходки» против дублей — реализовано: защитный интервал при возврате; сброс таймера долгим удержанием только администратором/старшим прорабом с аудитом; старый сброс не затирает новую погрузку (`docs/line-integrity-protocol.md`). Проверено живыми пробами.
3. Выбор дневной/ночной смены — реализовано: тип смены задаётся при открытии; время ходки подтверждается общим для смены.
4. Принадлежность материалов выбранной смене независимо от времени закрытия — материал из объёма обычных рейсов связывается со сменой автоматически (название/направление/назначение, коррекция рейса меняет объём, не дублирует материал). Проверено тестами на изолированной БД; полный пользовательский цикл через основные экраны — см. «Незавершённое».
5. Редактирование архивной смены параллельно активной — реализовано в тестовой ветке (архив: плашки объектов → смены, отчёт оверлеем, PNG); редактирование архивной смены не блокирует активную. Полный браузерный прогон сценария «архивная параллельно активной» — remnants, см. ниже.

Для каждого пункта при реальной задаче сверяйтесь с кодом и тестами: документы фиксируют решения, фактическое поведение — только код и прогоны.

- Модульная рабочая версия четвёртого поколения отозвана владельцем (ломала регистрацию и закрытие смены); её исходники (`app/src`) хранятся как архив. Актуальная рабочая версия собирается из линии `working-test` (прод-комплект в ветке `root`). Мёртвый тест-канал `test-app/` удалён 22.11.2026 после ревизии (см. `docs/opyt-oshibok.md`, п.8).
- DSM/Synology отображал устаревшее имя API-контейнера — история Synology закрыта, актуальный бэкенд на Ubuntu.
- Firebase Rules облачного проекта и опубликованная страница могут отставать от тестового кода ролей (см. test-3.3-requirements.md, «изменения подготовлены в тестовом коде… ещё не обновлены»).
