# Рабочая модульная версия

Актуальные исходники — `app/source/`, порядок блоков — `app/modules.json`.
`core/` содержит разделы ядра, `features/` — отдельные функции,
`patches/` — читаемые встроенные расширения, `styles/` — исходный CSS.

Сборка из корня: `python3 tools/build-release.py`.
Проверка: `python3 tools/verify-production-modules.py`.

Результаты: `index.html`, `sw.js`, `app/build-manifest.json`, `app/build/<hash>/`.
Их публикуют одним коммитом; старые build-каталоги сохраняют для открытых окон.
Новые исходники не используют старый каталог `app/src/`.

Рабочая база — `samosval-test`, прежние локальные ключи операторов сохранены.
Табель отсутствует в исходниках, навигации, правах и кэше. Тестовая версия имеет
отдельные исходники и сборку. Сборщик не меняет тестовую страницу и Firebase rules.
