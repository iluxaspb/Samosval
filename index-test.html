🪙 Игровые очки (предварительный расчёт)
Как считаются показатели

Текущая смена: число рейсов считается по сохранённым записям погрузок, объём — сумма их объёмов. Рейтинг ниже строится по последним загруженным событиям аудита (до 200), а не по всей истории. Повторно полученное событие с тем же ID учитывается один раз. Категории действий определяются по типу сохранённого события; записи без известного типа не включаются. Если исторические события недоступны, рейтинг может быть неполным. Источник — доступный журнал аудита, без дополнительных запросов и изменения прав.

Патчи применяются автоматически при загрузке. Если патч сломан — программа продолжит работать, а ошибка будет видна в консоли. Если хотите откатить изменения — выключите галочку или удалите патч, затем обновите страницу.
Кто уже отметил действие
Подробно

Было: общее сообщение о том, что действие уже выполнено другим пользователем.

Стало: номер машины, название отметки, сохранённое имя автора и время. Дополнительного запроса к серверу для имени нет.

Если выключить: вернутся общие сообщения. Защита от повторных рейсов и сохранённые данные продолжают работать.

Как проверить: на двух устройствах откройте одну машину и почти одновременно отметьте её погрузку. Сохраниться должен один рейс; второе устройство покажет имя автора сохранённой отметки. Повторите с «Приехал».

Ограничение: если автор старого изменения не сохранён, приложение прямо об этом сообщит. Проверка на двух реальных устройствах ещё нужна.

Как сообщить о проблеме: «Кто уже отметил действие; объект …; машина …; дата и время …; нажал …; ожидал имя …; увидел …; интернет был/не был; патч включён/выключен».
