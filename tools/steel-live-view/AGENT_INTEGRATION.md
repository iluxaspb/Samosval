# Предпросмотр в чате и передача управления

Это инструкция для подключения тестовой надстройки, не установленный плагин.
Правила проекта и глобальные настройки OpenCode автоматически не меняются.

## Действия агента

Перед работой убедиться, что pinned target — именно страница текущего MCP.
Использовать действительный путь текущего чата из web UI
`/server/<serverKey>/session/<sessionID>`, а не ID Steel, не ID другого чата.
В окружение агента передать `VIEW_ORIGIN` и существующий `OPENCODE_PASSWORD`
защищённым способом, не включать пароль в команду, сообщение или URL.

```sh
node tools/steel-live-view/agent-browser.mjs show /server/<serverKey>/session/<sessionID>
```

Панель автоматически откроется в этом чате приблизительно через секунду.
Это панель поверх web UI, а не сохранённое вложение сообщения. Переход на другой
чат скрывает её. Привязка одна на весь sidecar и не является ACL пользователей.

Когда требуется логин, пароль или 2FA:

1. Закончить текущий MCP-вызов. Не оставлять фоновые браузерные действия.
2. Сообщить пользователю, что нужен его вход непосредственно в браузере.
3. Запустить ожидание:

```sh
node tools/steel-live-view/agent-browser.mjs login /server/<serverKey>/session/<sessionID>
```

4. Пока команда ждёт, **не вызывать MCP, не читать DOM/поля, не снимать экран,
   не записывать видео/трейсы и не запускать другую браузерную автоматизацию**.
   Не передавать эту работу другому агенту. Кадры для пользователя продолжают
   передаваться; надстройка не сохраняет их и введённый текст на диск.
5. Пользователь выбирает «Ручное управление», входит на сайте и нажимает
   «Я вошёл — продолжить». Кнопка очищает локальное поле и серверно отзывает
   ручной режим у всех подключённых viewer-соединений.
6. Продолжать только после успешного завершения команды ожидания. Закрытие
   панели не является согласием продолжить. Тайм-аут, отмена или ошибка
   соединения не дают разрешения продолжить. После перезапуска sidecar
   передача управления считается отменённой; заново согласовать продолжение.

Команда возвращает только состояние передачи управления, не логин, пароль,
cookies или DOM. «Продолжить» не доказывает успешную авторизацию на сайте.
Повторный `show` не может снять ожидание входа.

```sh
node tools/steel-live-view/agent-browser.mjs status
node tools/steel-live-view/agent-browser.mjs finish /server/<serverKey>/session/<sessionID>
```

`finish` отмечает окончание работы, не закрывая страницу и не выходя из аккаунта.
Желаемый выход из сайта согласовать отдельно.

## Ограничения защиты

Ожидание агента **кооперативное**: прямой MCP/CDP существует вне sidecar.
Панель не способна технически запретить другому агенту или подключению читать
страницу. Для строгой изоляции требуется отдельный MCP-gateway с блокировкой
вызовов на время ручного входа и проверкой уже выполняющихся операций.
Без такого gateway не обещать пользователю абсолютную приватность от всех
подключённых клиентов. Любой обладатель пароля OpenCode имеет доступ к панели.

Это не автоматическое распознавание логин-форм. Агент явно вызывает `show` и
`login`; глобальные хуки OpenCode здесь не установлены. На рабочем адресе
Synology функция появится только после отдельно проверенного запуска sidecar
и подключения агента по этому протоколу.
