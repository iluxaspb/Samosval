# 3.4.50 — Сохранение позиции карточки техники

После сохранения часов во вкладке «Смена → Техника» список остаётся на прежнем месте. Это действует для обычного ввода, быстрых часов, последних пяти дней и обновления текущей смены. Переход на другую дату, смену, объект или под-вкладку открывает новый список с начала.

Выпуск для тестового и рабочего каналов. Схема данных, Firebase Rules, очередь, порядок техники и расчёты не менялись.

Резервная ветка перед публикацией: `backup/before-3.4.50-scroll-20261028`, исходный коммит `82c73d9c0f6c46c6d99f6073f8bec35f5e82142a`. Для отката восстанавливать файлы выпуска отдельным коммитом, без сброса последующих изменений.

Проверки:
- Новый мобильный браузерный тест с 30 карточками для обоих каналов: ручной ввод 5 часов, пресет 12, последние пять дней, обновление, отмена, переход между датами.
- Этот тест воспроизводит исходную ошибку до исправления.
- 45 тестов доменной логики табеля.
- Проверки формул, диапазонов, числового ввода, собственных/наёмных машин, сенсорной прокрутки и открытия без сети.
- Детерминированная сборка и проверка хешей ресурсов.

Известное ограничение существующего full-browser.cjs: ожидает начальную вкладку «Заявки», хотя текущая версия открывает «Смена». Та же ошибка подтверждена на неизменённом исходном коде 3.4.49.
