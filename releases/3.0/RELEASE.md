# Выпуск 3.0

Статус подготовки: выпуск в рабочую программу разрешён пользователем 24.10.2026. Публикация Rules выполняется пользователем; состояние Firebase Console автоматически не проверялось.

## Подключения и данные

- Основная страница: Firebase `samosval-test`, workspace `main_workspace` — точная конфигурация прежнего index.html.
- Тестовая страница index-test.html: Firebase `samosval-offline`; файл не изменяется.
- Копирование, очистка и импорт данных не выполняются. Программа продолжает использовать существующие учётные записи, роли, смену и коллекции.
- Настройка cycleMinutes и установленные рабочие патчи автоматически не перезаписываются.
- Ссылки manifest.json и icon.svg сохранены.

## Правила и переключение

Пользователь прислал текущие рабочие правила; их точная копия сохранена в firestore-before-release.rules. Обновлённый файл firestore-v3.rules передан для публикации в рабочем проекте samosval-test. Он разрешает проверенную запись истории и делегированную отмену/восстановление с учётом прав роли.

Перед выпуском повторно сверены исходная основная страница, подготовленная сборка и неизменность тестового файла. Переключение кода выполняется слиянием PR в root; после него проверяется публикация GitHub Pages. Принудительная перезагрузка устройств не выполняется. Операторы обновляют страницу после завершения ожидающей синхронизации и проверяют версию 3.0, роль, текущий объект и счётчики.

## Отключаемая анимация и настройки

Файл patches/line-motion-settings-v1.js подготовлен отдельно для установки обычным патчем «Замена функции». Не вшит в index.html и автоматически в рабочую базу не записывается. Его можно включить и выключить штатным переключателем. Установленный в тестовой базе патч сам по себе не переносится в рабочую.

## Проверки

Пройдены проверки JavaScript всех скриптов и встроенных патчей, совпадения Firebase-конфигурации и путей коллекций, изоляции офлайн-очередей, сохранения PWA-ссылок и отсутствия кода вне script. Проверены офлайн-повтор без лишнего рейса, общее время ходки, сброс таймера, конфликт сброса и повторная доставка аудита. Проверены модалки, сохранение прав и открытие журнала при недоступном сервере.

В локальном Firestore Emulator проверены запись и отмена/восстановление истории, защита от подмены снимков, конкурентная отмена, один рейс при двух погрузках и пакетные операции. Старый формат записи прибытия, погрузки, ТТН, аудита и уведомлений без новой истории разрешён обновлёнными правилами. Исходные правила воспроизводят отказ делегированной отмены. Рабочая база не использовалась для тестовых записей.

## Откат кода

Точная предыдущая страница сохранена в releases/3.0/index-before-release.html.txt (Git blob 8866cbb04813057264d961ac11f4218e0a1c94b6). Для отката восстановить её содержимое в index.html отдельным коммитом. Это резерв кода, не резерв базы.

Откат не должен удалять записанные рейсы или очередь действий на устройствах. Новые дополнительные поля не удалять. Устройства с ожидающими офлайн-действиями сначала синхронизировать. Тестовую страницу и её базу при откате не менять.
