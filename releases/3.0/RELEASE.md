# Выпуск 3.0

Статус: подготовлен, основная ветка ещё не переключена.

## Подключения

- Основная страница: Firebase `samosval-test`, workspace `main_workspace` — точная конфигурация прежнего index.html.
- Тестовая страница index-test.html: Firebase `samosval-offline`; файл не изменяется.
- Копирование, очистка или импорт данных не выполняются. Сохраняются существующие пользователи, роли, смена и коллекции.
- Ссылки manifest.json и icon.svg сохранены.

## Перед переключением

1. Получить текущие опубликованные Firestore Rules проекта samosval-test и сравнить с firestore-v3.rules. Файл в GitHub не подтверждает, какие правила реально опубликованы.
2. Проверить совместимость правил с открытой старой версией: arrival/load/TTN, уведомления, audit. Новая версия записывает историю в той же транзакции, что и действие; запрет audit приведёт к отказу всей записи.
3. Уточнить общую настройку cycleMinutes. Существующее значение appConfig сохраняется; автоматической перезаписи нет.
4. Сделать свежую резервную копию рабочей базы штатным способом и проверить завершение ожидающих операций у операторов.
5. Сравнить актуальную root с base_commit в release-manifest.json. При чужих изменениях пересобрать на свежей версии.
6. После проверки правил переключить index.html атомарно через merge этого изменения. Не перезагружать устройства принудительно. После синхронизации действий операторы обновляют страницу и проверяют роль, текущий объект и счётчики.

## Отключаемая анимация и настройки

Файл patches/line-motion-settings-v1.js подготовлен отдельно для установки обычным патчем «Замена функции». Не вшит в index.html и автоматически в рабочую базу не записывается. Поэтому рабочие установленные патчи сохраняются, а экспериментальную анимацию можно включить и выключить штатным переключателем. Уже установленный в тестовой базе патч сам по себе не переносится в рабочую.

## Проверки

Пройдены проверки JavaScript всех скриптов и встроенных патчей, совпадения Firebase-конфигурации и путей коллекций, изоляции офлайн-очередей, сохранения PWA-ссылок, отсутствия кода вне script. Повторно выполнены сценарии офлайн-повтора без лишнего рейса, общего времени ходки, сброса таймера, конфликта сброса и повторной доставки аудита. Проверены модалки, сохранение прав и открытие журнала при недоступном сервере.

Эти проверки используют изолированные модели и DOM, а не рабочую базу. Действующие серверные Rules не прочитаны: автоматическая проверка доступа заблокировала вход в Google. Запись тестовых рейсов в рабочую смену не выполнялась.

## Откат кода

Точная предыдущая страница сохранена в releases/3.0/index-before-release.html.txt (Git blob 8866cbb04813057264d961ac11f4218e0a1c94b6). Для отката восстановить её содержимое в index.html и опубликовать отдельным коммитом. Это резерв кода, не резерв базы.

Откат не должен удалять уже записанные рейсы или очередь действий на устройствах. Новые дополнительные поля не удалять. Устройства с ожидающими офлайн-действиями сначала синхронизировать. Тестовую страницу и её базу при откате не менять.
