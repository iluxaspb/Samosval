# 3.4.1 — закрытие смены, PNG и текстовые уведомления MAX

Срочный выпуск по поручению владельца от 25 октября 2026. Рабочий файл остаётся однофайловым; `index.html` и `recovery-3.4.html` одинаковы, номер версии зелёный. Тестовая версия и Firebase-проект не меняются.

## Исправление

В 3.4 архив сохранялся перед ожиданием PDF для MAX, затем выполнялась одна большая операция очистки. Зависшая генерация изображения/PDF либо лимит истории/Firestore оставляли архив созданным, а смену открытой.

В 3.4.1 смена сначала получает признак закрытия в транзакции: существующий механизм отметок отвергает новые рейсы для неактивной смены. Серверные рейсы сохраняются под постоянным ID архива; транзакция создаёт архив только при отсутствии, поэтому одновременное закрытие с двух устройств не перезаписывает уже сохранённый полный отчёт. Только после подтверждённого сохранения начинается очистка: до 20 записей для администратора или 4 для других ролей за операцию, с сохранением действующего журнала истории. Повторная попытка использует тот же архив и проверяет наличие оставшихся рейсов в нём. После очистки удаляется документ именно закрываемой смены, обновляется экран. Ошибка оставляет возможность повторить закрытие. Архивы, созданные старыми неудачными попытками, автоматически не удаляются.

Все штатные отчёты — текущий, ГАИ, архив и зарегистрированные расширениями — скачиваются как PNG. Сохраняется полный лист без PDF-пагинации; размер canvas и ожидание шрифтов/отрисовки ограничены. Старая библиотека html2pdf используется только как обёртка над html2canvas, PDF не создаётся.

Отправка отчётов в MAX и её настройки удалены. Обычные уведомления остаются текстовыми, включая прежние настройки уведомлений с картинками номеров. Старые задания документов/изображений удаляются из очереди MAX; локальный журнал отметок не затрагивается.

## Проверки

- `node tests/shift-close/regression.cjs` — закрытие, повтор после сбоя, архив перед удалением, ограниченные порции очистки, защита от повторного нажатия и смены ID.
- `node tests/shift-close/max-text.cjs` — базовый отправитель, патч повторов и оформление номера отправляют только текст; старые файлы не отправляются, журнал действий сохранён.
- `node tests/png-export/regression.cjs` — PNG текущего/ГАИ/архивного/плагинного отчёта, MIME/имена, полный canvas, ограничения размера и ожиданий, очистка DOM при ошибках.
- Синтаксическая проверка встроенных скриптов и запечённых патчей; сравнение основного и восстановительного HTML.

Автоматические проверки используют изолированные имитации браузера и Firestore. Они не заменяют проверку закрытия реальной смены и загрузки PNG в Chrome на телефоне. Рабочие данные для тестов не изменялись; правила Firestore не публиковались. Статус доставки проверяется по GitHub Pages после отправки коммита.
